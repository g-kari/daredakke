# 更新履歴

## 2026-10-10: 入力破棄確認での連続Escape（本番反映待ち）

- 破棄確認にフォーカスした直後でも、2回目のEscapeで編集に戻れます。人・アカウント・JSONの入力を保持し、元の入力欄へフォーカスを戻します。保存や破棄を自動実行しません。
- 既存Chromium回帰で確認した連続Escapeの失敗を対象に、確認内容側でキーを処理します。人物変更時の保護・明示的な破棄・通常のキー操作を維持し、依存・認証・保存・CI設定は変更しません。複数キーワード検索が原因だと断定していません。
- 架空データで3種類の入力とdesktop/mobileの繰り返し操作を追加検証します。合格状況と本番への反映は対象PRと最終SHAのCI記録を参照してください。本人ログイン・実データ・実機は未検証です。

## 2026-10-10: 複数キーワード検索（本番反映待ち）

- 名前・別名・タグ・メモと関連アカウントの複数の手掛かりから、人を絞り込めます。空白で区切ったキーワードをすべて含む記録を探し、大小文字を区別しません。前後・連続・全角の空白、逆順のキーワードに対応します。
- 人・未整理・重複候補で同じ照合規則を使い、既存WebMCPの人検索を画面と共有します。検索欄に使い方の短い説明を追加し、空白だけの検索では通常の全件・空状態を表示します。
- 記号は文字として扱います。100文字の検索制限、サービス絞り込み、記録順、選択・未保存入力・本人変更時の保護を維持します。検索で記録を書き換えたり、名前から同一人物を推測して自動紐づけしたりしません。
- 合成データで通常の型・全テスト・ビルド・ローカルD1・dry-run・bundleと、固定Chromiumのデスクトップ／モバイル回帰を検証します。本番の私的記録、本人ログイン、実機と実WebMCP互換性は対象外です。最終コミットのCIと対象PRを検証結果の根拠としてください。
- 本番への反映状況は対象PRの記録を参照してください。API・保存文書・認証・D1・依存や配備設定は変更しません。

## 未リリース

- JSON読み込みに内容の確認画面を追加します。現在・読み込み後の件数と、同じIDでの追加・更新・取り除く・変更なしを、人とアカウントごとに表示します。未整理アカウントと同じURLの重複候補、入力元と対象の保存先も示します。
- 内容の確認だけでは保存しません。JSONの編集後は確認をやり直し、空の記録へ置き換える場合は明示的な確認を選んでから、最後の置き換え確認に進みます。キャンセルや通常の保存失敗では入力と確認内容を保持します。
- ログイン確認が始まった場合は最後の確認ダイアログを閉じます。同じ本人だと確認できた後も、残した読み込み内容から自分でもう一度置き換えを確認します。確認中は従来どおり記録と入力画面を非表示にします。
- 既存のversion 1と旧friend-record形式、直前の状態を残す復元、本人変更時の入力消去を維持します。保存文書・API・認証・D1構造は変更しません。

- B2-4のプロフィール中心の配置をもとに、暗いグレーと控えめなラベンダーの画面へ更新します。デスクトップではサービス絞り込み・人の一覧・選択した人のプロフィールを並べ、モバイルでは一覧から詳細を開きます。
- 人・アカウントの追加を一覧側に、編集とアカウント紐づけを人の詳細側にまとめます。統合と削除は詳細内の「統合・削除」、JSONと復元は画面下の保存ツールから使えます。
- 手入力・未接続の状態、デモとマイレコードの分離、未保存入力と本人変更の保護を維持します。保存文書・API・認証・D1構造は変更しません。
- 架空APIを使うブラウザー回帰テストを34ケースへ拡張し、プロフィール表示、検索・サービス絞り込み、文脈に合った編集と追加、バックアップ、長文の折り返しも確認します。1280pxと390pxの画面証拠を対象コミットのCI成果物に保存します。合格状況はそのCI結果を参照してください。

- 人・アカウントの編集、JSON読み込みで、保存前の入力を閉じる際に破棄の確認を表示します。Escape、閉じるボタン、背景クリック、キャンセルに対応します。「編集を続ける」では入力をそのまま残し、背景クリック・タップ後も元の入力欄へフォーカスを戻します。
- 未変更の入力は確認なしで閉じられます。保存先の切り替えと、入力がある間のページ離脱にも確認を行います。ページ離脱の警告表示はブラウザーの仕様に従います。
- ログインの変更・確認失敗時は、従来どおり古い入力と記録を消します。下書きを端末やサーバーへ自動保存する機能は追加していません。
