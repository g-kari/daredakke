# 更新履歴

## 未リリース

- 人・アカウントの編集、JSON読み込みで、保存前の入力を閉じる際に破棄の確認を表示します。Escape、閉じるボタン、背景クリック、キャンセルに対応します。「編集を続ける」では入力をそのまま残し、背景クリック・タップ後も元の入力欄へフォーカスを戻します。
- 未変更の入力は確認なしで閉じられます。保存先の切り替えと、入力がある間のページ離脱にも確認を行います。ページ離脱の警告表示はブラウザーの仕様に従います。
- ログインの変更・確認失敗時は、従来どおり古い入力と記録を消します。下書きを端末やサーバーへ自動保存する機能は追加していません。

検証範囲: 架空データによる差分判定、実際の画面コールバック、既存の認証・保存・D1・bundleテスト、型検証、画面ビルド、配備しないdry-run。実ブラウザーの確認ダイアログの重なり・フォーカス復帰・390pxのモバイル幅は、架空APIのChromium回帰テスト20ケースで確認します。合格状況は対象コミットのCI結果を参照してください。本番Accessとの接続、実機スマートフォン、支援技術の操作は未検証です。
