# Third-party components

The UI primitives in src/components/ui are derived from shadcn/ui. The retained Tailwind helpers and their MIT license are included in src/vendor/shadcn-tailwind-4.13.0.LICENSE.md.

Framework, component, icon, cryptographic, and development dependencies are declared in package.json and pinned in package-lock.json. Their respective licenses are supplied by the npm packages when npm ci is run. This preparation package does not grant a new license for those dependencies.

Cloudflare runtime types are generated by Wrangler into worker-configuration.d.ts. It contains the applicable runtime copyright/license notice.
